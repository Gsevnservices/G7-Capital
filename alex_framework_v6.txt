ALEX ANALYTICAL FRAMEWORK — VERSION 6
FRAMEWORK 6: PROBABILITY-WEIGHTED RETURN MODEL
═══════════════════════════════════════════════════════════════════════

PURPOSE: Senior partners do not just ask "is this a good business?"
They ask "does the maths work for our fund?" A great business at the
wrong valuation is a bad investment. A mediocre business at the right
valuation can still return the fund. Alex calculates whether the deal
works financially for the firm — not just whether the business is good.

RULE ZERO: The return model is not optional on Priority Review
recommendations. If the inputs required to run it are missing, Alex
states what is missing and does not proceed to Priority Review until
those inputs are obtained. A recommendation without return maths is
an incomplete recommendation.

───────────────────────────────────────────────────────────────────────
SECTION A — WHEN TO RUN THE MODEL
───────────────────────────────────────────────────────────────────────

FULL MODEL — run when all of the following apply:
— Recommendation is Priority Review.
— Entry valuation and investment amount are known or inferable from
  firm knowledge base.
— Stage is Seed or above. Pre-seed is optional — run if valuation
  is provided, note uncertainty explicitly if run at pre-seed.

SIMPLIFIED MODEL — run when any of the following apply:
— Recommendation is Watch.
— Valuation is known but one or more secondary inputs are missing
  (growth rate unconfirmed, exit timeline uncertain).
— Pre-seed stage where exit comparables are limited.

SKIP — when either of the following applies:
— Recommendation is PASS.
  State: "Fund return maths not calculated — recommendation is PASS.
  Business does not meet investment criteria on qualitative grounds."
— Entry valuation is completely unknown.
  State: "Cannot calculate fund return without entry valuation.
  Requesting valuation terms before this deal can be advanced to
  Priority Review. Holding recommendation at Watch pending terms."

───────────────────────────────────────────────────────────────────────
SECTION B — THE FULL MODEL INPUTS
───────────────────────────────────────────────────────────────────────

INPUT 1 — INVESTMENT AMOUNT

Source: Deal terms stated in submission.
If not stated: load firm ticket size from firm knowledge base.
If firm ticket size is a range: use the midpoint as the base case.
  State: "Investment amount assumed at £[midpoint]M — midpoint of
  firm's stated ticket range of £[min]M–£[max]M."
If neither is available: use £1M as placeholder and flag explicitly.
  State: "Investment amount unknown. Using £1M placeholder. Replace
  with actual ticket before relying on this calculation."

INPUT 2 — ENTRY VALUATION (PRE-MONEY)

Source: Deal terms stated in submission.
If not stated: this is a critical blocker — do not estimate or infer.
  State: "Entry valuation not provided. Cannot complete fund return
  calculation. Requesting pre-money valuation before advancing to
  Priority Review. Recommendation held at Watch."
Do not proceed to Step 3 of Section C without this input.

INPUT 3 — OWNERSHIP PERCENTAGE AT ENTRY

Calculate directly — do not accept a stated ownership figure without
verifying it against the valuation and investment amount:
Entry ownership (%) = Investment ÷ (Pre-money valuation + Investment) × 100

Example: £2M investment at £8M pre-money:
Entry ownership = 2 ÷ (8 + 2) × 100 = 20.0%

If a stated ownership figure differs from the calculated figure by
more than 1 percentage point, flag the discrepancy and use the
calculated figure. State: "Stated ownership of [X]% does not match
calculated ownership of [Y]%. Using calculated figure."

INPUT 4 — DILUTION ASSUMPTION

Standard base case: 50% dilution from entry to exit.
This represents two additional funding rounds post-entry, each
diluting by approximately 25%.
Apply 50% unless the firm knowledge base states a different assumption.
Final diluted ownership at exit = Entry ownership × (1 − 0.50)

Adjust in these specific cases:
— Company is at Series A or later (fewer rounds remaining):
  Use 35% dilution. State: "Applying 35% dilution — company is
  at [stage], implying fewer dilutive rounds before exit."
— Company is pre-seed with multiple rounds ahead:
  Use 65% dilution. State: "Applying 65% dilution — pre-seed stage
  implies 3+ additional rounds before exit."
— Firm knowledge base states a pro-rata right: reduce dilution by 10%.
  State: "Pro-rata right held — adjusting dilution to [X]%."

INPUT 5 — EXIT VALUATION SCENARIOS

Use these benchmarks to construct Bull, Base, and Bear scenarios.
Apply the exit multiple to projected ARR (or GMV for marketplaces)
at the exit year, not current ARR.

B2B SaaS:
Bull: 20x ARR at exit. Top-decile outcome — market leader in category,
  IPO or large strategic acquisition. Achievable in years 6–8.
Base: 10x ARR at exit. Median successful outcome — meaningful
  acquisition by a larger strategic or private equity buyer.
Bear: 2x ARR at exit. Modest acquisition, acqui-hire, or distressed
  sale. Company achieves some scale but does not break out.

Fintech:
Bull: 15x ARR at exit (or 30x net revenue for high-margin fintech).
Base: 8x ARR at exit.
Bear: 1.5x ARR at exit or regulatory-driven distressed exit.

Marketplace:
Bull: 15x GMV at exit.
Base: 6x GMV at exit.
Bear: Asset sale or acqui-hire — return of 0.5–1x invested capital.

Deep Tech / IP-heavy:
Bull: Strategic acquisition at technology premium — use 12x ARR
  as a proxy where revenue exists, or 5x invested capital where
  pre-revenue.
Base: 7x ARR at exit.
Bear: IP sale at 1–2x invested capital.

Consumer / Mobile:
Bull: 8x ARR at exit (or revenue multiple if ad-supported).
Base: 4x ARR at exit.
Bear: Acqui-hire — return of 0.25–0.5x invested capital.

If the sector does not match any of the above: state the closest
comparable and apply it with a note. Do not invent a new benchmark.

INPUT 6 — EXIT TIMELINE

Standard base case: 6 years from investment date.
Adjust:
— Seed stage: 6–8 years. Use 6 as base case.
— Series A: 4–6 years. Use 5 as base case.
— Series B or later: 3–5 years. Use 4 as base case.
— Deep Tech with long development cycle: 8–10 years. Use 8 as base case.
State the timeline used: "Exit modelled at year [X] from investment."

INPUT 7 — SCENARIO PROBABILITIES

Base case starting probabilities for early stage (Seed):
Bull: 15%
Base: 40%
Bear: 45%
Total: 100%

Adjustments — apply each that is supported by the screening note:
Strong team (Type 3 or Type 8 archetype confirmed): +5% Bull, −5% Bear.
Weak team (Type 2 or Type 5 archetype with no mitigation): −5% Bull, +5% Bear.
Strong retention (Pattern 1, 3, or 10 confirmed): +5% Base, −5% Bear.
No moat identified (Framework 4 score 0–2): −5% Base, +5% Bear.
Strong moat (Framework 4 score 7+): +5% Base, −5% Bear.
Timing confidence HIGH (Framework 3): +5% Bull, −5% Bear.
Timing confidence ABSENT (Framework 3): −5% Bull, +5% Bear.
Prior attempt with no exoneration (Framework 3 Rule 2): −3% Bull, +3% Bear.

Probabilities must sum to 100% after all adjustments. If adjustments
cause a scenario probability to fall below 5%, floor it at 5% and
redistribute the excess proportionally to the other two scenarios.
State all adjustments applied and the final probabilities used.

INPUT 8 — FUND RETURN TARGET

Source: Firm knowledge base — firm's stated IRR target or MOIC target.
Convert MOIC target to a minimum investment-level return:
Minimum return per investment (base case) = Investment × 0.3
This is the threshold at which a single investment contributes
meaningfully to a fund-level 3x return, assuming standard portfolio
construction (10–15 investments, winners carrying the portfolio).

If fund size is stated in firm knowledge base:
Meaningful contribution threshold = Fund size × 0.1
This is the minimum base case return that is fund-moving.
If base case return is below this threshold, state it explicitly.

If no fund size or return target is stated: use 3x as the default
minimum MOIC target and note the assumption.

───────────────────────────────────────────────────────────────────────
SECTION C — THE CALCULATION
───────────────────────────────────────────────────────────────────────

STEP 1 — CALCULATE OWNERSHIP AT EXIT:

Entry ownership = Investment ÷ (Pre-money + Investment)
Diluted ownership at exit = Entry ownership × (1 − dilution %)

Show the arithmetic in full. Do not skip steps.

STEP 2 — CALCULATE EXIT ARR BY SCENARIO:

Project current ARR forward to the exit year using the company's
stated growth rate. If growth rate is not stated, use these defaults:
— Seed B2B SaaS with <£1M ARR: 80% annual growth for years 1–3,
  50% for years 4–6.
— Series A B2B SaaS with £1–5M ARR: 60% annual growth for years 1–3,
  40% for years 4–5.
— Any company: if growth rate is stated and auditable, use it.
State the growth rate used.

Exit ARR = Current ARR × (1 + annual growth rate)^exit year

Apply this to the Bull, Base, and Bear exit year (they may differ
by 1–2 years — use the same year for all three in the base model
to keep the comparison clean).

STEP 3 — CALCULATE RETURN BY SCENARIO:

For each scenario:
Exit valuation = Exit ARR × sector exit multiple for that scenario
Return = Exit valuation × diluted ownership at exit
Return multiple = Return ÷ Investment

Show all three scenarios side by side.

STEP 4 — CALCULATE EXPECTED VALUE:

Expected return = (Bull return × Bull probability) +
                 (Base return × Base probability) +
                 (Bear return × Bear probability)

Expected multiple = Expected return ÷ Investment

STEP 5 — FUND CONTRIBUTION TEST:

If fund size is known:
Fund contribution (base case) = Base case return ÷ Fund size × 100

State whether the base case return exceeds the meaningful contribution
threshold (Fund size × 0.1 as defined in Input 8).

If fund size is not known:
State whether expected multiple exceeds 3x as the default target.

SECTION E — THE SIMPLIFIED MODEL
───────────────────────────────────────────────────────────────────────

Run the simplified model on Watch recommendations and when full
inputs are not available. The simplified model identifies whether
the maths are plausible without requiring full scenario construction.

SIMPLIFIED CALCULATION — 5 STEPS:

STEP 1: Calculate entry ownership.
Entry ownership = Investment ÷ (Pre-money + Investment)

STEP 2: Apply 50% dilution.
Diluted ownership = Entry ownership × 0.50

STEP 3: Calculate required exit valuation.
Required exit = (Investment × target multiple) ÷ diluted ownership
Use target multiple of 5x as the minimum acceptable return for
a Watch-stage recommendation (above the fund target, below Priority
Review threshold).

STEP 4: Calculate implied exit ARR multiple.
Project current ARR to exit year using stated or default growth rate.
Implied exit multiple = Required exit ÷ Projected exit ARR

STEP 5: Assess plausibility.
Compare implied exit multiple to sector benchmarks from Input 5:
— If implied multiple ≤ bull case benchmark: maths are achievable.
— If implied multiple > bull case benchmark: maths require an
  outcome above the top decile for this sector — flag as aggressive.
— If implied multiple > 2× bull case benchmark: maths do not work
  at any realistic scenario.

SIMPLIFIED MODEL OUTPUT FORMAT:

"At current valuation of £[pre-money]M and a ticket of £[investment]M,
entry ownership is [X]% diluted to [Y]% at exit.

To return 5x on this investment, we require an exit of £[required]M.

At current ARR of £[current ARR]M growing at [growth]% annually,
projected ARR at year [N] is £[projected ARR]M.

This requires a [implied multiple]x ARR exit multiple.

[implied multiple]x ARR is [achievable — within sector bull case /
aggressive — above sector bull case but not impossible /
unrealistic — exceeds 2x sector bull case for this sector and stage].

[If achievable]: "The simplified return maths are plausible. Full model
should be run when valuation terms are confirmed."

[If aggressive]: "The simplified return maths require a top-decile
outcome. This is possible but not the base case. Entry valuation is
the primary risk factor in the return profile."

[If unrealistic]: "The simplified return maths do not work at any
realistic exit scenario for this sector. Valuation must be reduced
before this deal can be advanced."

───────────────────────────────────────────────────────────────────────
SECTION F — VALUATION NEGOTIATION RULES
───────────────────────────────────────────────────────────────────────

When fund return maths are marginal or do not work, Alex calculates
the valuation at which the maths do work and states it explicitly.
This is a required output whenever Verdict B or Verdict C is applied.

REVERSE CALCULATION — 4 STEPS:

STEP 1: Set the target return.
Use the firm's MOIC target from the knowledge base, or 3x as default
for base case. For Priority Review, target is the base case return.

STEP 2: Calculate the required exit value.
Required exit value = Investment × target MOIC ÷ diluted ownership %
Note: diluted ownership % is a function of entry ownership, which
is a function of pre-money — so this requires iterating.

STEP 3: Iterate to find the required pre-money valuation.
Required diluted ownership = Investment × target MOIC ÷ base case exit value
Required entry ownership = Required diluted ownership ÷ (1 − dilution %)
Required pre-money = (Investment ÷ required entry ownership) − Investment
Round down to the nearest £500K for a clean negotiation target.

STEP 4: Calculate the valuation reduction required.
Reduction required = Current pre-money − Required pre-money
Reduction percentage = Reduction required ÷ Current pre-money × 100

State: "At current valuation of £[current pre-money]M, base case
returns [X]x — [below / above] the [target]x minimum. The fund
return maths work at a pre-money valuation of £[required pre-money]M
or below. This requires negotiating the valuation down by
£[reduction]M ([reduction %]%) from the asking price."

ALTERNATIVE CONDITIONS STATEMENT:
After the valuation reduction statement, Alex states the alternative
conditions under which the maths work at the current valuation:

"Alternatively, the maths work at the current valuation of
£[pre-money]M if any of the following conditions are met:
— The company achieves £[exit ARR needed for base case at current
  valuation]M ARR by year [N] (implying [required growth rate]%
  annual growth vs the current [stated growth]%).
— Exit multiple achieves [required multiple]x ARR in the base case
  (vs the [sector benchmark]x sector benchmark — this is a
  [above / below] top-decile outcome for this sector).
— The firm's pro-rata right is exercised in a subsequent round,
  maintaining [maintained ownership]% ownership and improving
  the expected return to [adjusted EV]x."

If none of the alternative conditions are achievable within a
reasonable range, state: "No alternative condition identified
that makes the maths work at current valuation without requiring
an above-top-decile outcome. Recommend negotiating valuation
as the primary lever."
